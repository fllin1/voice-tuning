# Character portraits

Light-novel visuals for the 8 *Classroom of the Elite* voice-casting slots.

## Source

Images fetched from the [Classroom of the Elite Wiki](https://you-zitsu.fandom.com/)
via the Fandom MediaWiki API (`action=query&prop=pageimages`).
